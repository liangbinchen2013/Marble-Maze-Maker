# 弹珠迷宫 DIY —— 可视化编辑器

一个本地网页应用：在浏览器里画墙、挖孔、调尺寸，实时校验能不能通关，然后导出 STL 和 360° 环绕 GIF。

[Makerworld模型](https://makerworld.com.cn/zh/models/3262461-dan-zhu-mi-gong#profileId-3854015)

## 启动

双击上一层的 **`启动迷宫编辑器.bat`**，或：

```powershell
cd maze_studio
python server.py --port 8000 --open
```

浏览器打开 <http://127.0.0.1:8000>。

依赖（只需装一次）：

```powershell
pip install flask trimesh manifold3d numpy scipy pillow vtk
```

## 界面

```
┌ 工具 ────────┬ 画布 ──────────────┬ 校验 ────────┐
│ 画墙 / 格孔   │                    │ ✓ 可以通关    │
│ 交点 / 移动   │   点线编辑迷宫       │ 30 步         │
│ 起点 / 终点   │                    │ 球心净宽 通过  │
├ 尺寸 ────────┤                    ├ 导出 ────────┤
│ 格数 / 路宽   │                    │ 生成 3D 模型   │
│ 墙厚 / 底板   │                    │ 生成环绕 GIF   │
│ 球径 / 孔径   │                    │               │
└──────────────┴────────────────────┴───────────────┘
```

### 工具

| 工具 | 操作 |
|---|---|
| **画墙** | 在格线上按住拖动 = 连续画墙；在已有墙上拖 = 擦除。外框固定不可编辑 |
| **格孔** | 点格子循环：无孔 → Ø(格孔直径) → Ø18 → 无孔 |
| **交点** | 点四个格子的交点，加 / 去一个 Ø18 的大孔（就是草图里那种压在格线上的孔） |
| **移动** | 拖动任意孔到任意位置，**不吸附格子**（自由偏移，0.1 mm 精度）。双击归零；`Delete` 删除；方向键微调 0.5 mm，按住 `Shift` 2 mm |
| **起点 / 终点** | 点格子设置 S / T，入口和出口的方向在左下角选 |

快捷键 `1`~`6` 切换工具（画墙 / 格孔 / 交点 / 移动 / 起点 / 终点）。

> 墙必须留在格线上（否则会切断通道），S / T 也按格子定位；只有孔是自由坐标。

### 实时校验

每次改动 0.2 秒后自动向后端要一次结果：

- **最短步数**：按格子走的最短路（避开格孔）
- **连通格数**：被墙封死的格子会少于总数，会给出警告
- **球心净宽**：把球当 Ø14 的圆，按 0.5 mm 栅格做泛洪，验证球心能不能真的从 S 走到 T
  （格心能走 ≠ 球能走，比如 2×2 房里放一个 Ø18 的孔，格心路径是通的，但球必须贴墙才过得去）
- **警告**：孔切墙、孔粘连、出口比球小、入口孔顶超过墙高……

### 导出

| 按钮 | 产物 |
|---|---|
| **生成 3D 模型** | `outputs/maze_*.stl`（水密单实体）+ 一张 3D 渲染图 + 三角面/体积/耗材 |
| **生成环绕 GIF** | 72 帧 360° 环绕动画（720×540，约 40 秒） |
| **导出 / 导入配置** | 迷宫存成 JSON，可以发给别人直接打开 |

## 文件

| 文件 | 说明 |
|---|---|
| `server.py` | Flask 服务：`/api/check` `/api/build` `/api/gif` `/api/preset/classic` `/api/random` |
| `maze_core.py` | 内核：Config → manifold 实体 / 校验 / 栅格泛洪 |
| `maze_render3d.py` | VTK 离屏渲染：3D 静帧 + 环绕 GIF |
| `ui/` | 前端（原生 JS + Canvas，无构建步骤） |
| `outputs/` | 生成的 STL / PNG / GIF |

## 接口速查

```powershell
# 经典 8×8 配置
curl http://127.0.0.1:8000/api/preset/classic

# 校验
curl -X POST http://127.0.0.1:8000/api/check -H "Content-Type: application/json" -d "@cfg.json"

# 生成 STL + 预览图
curl -X POST http://127.0.0.1:8000/api/build -H "Content-Type: application/json" -d "@cfg.json"
```

## 尺寸链

```
总宽 = 格数 × 路宽 + (格数 + 1) × 墙厚
8 格 × 18 + 9 × 3.375 = 174.375 mm
```

改「格数」或「路宽」时外形会跟着变，右下角画布会实时显示当前外形尺寸。
